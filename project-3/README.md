# SQL DATA ANALYSIS

## Introduction

This project focuses on using SQL to analyze an e-commerce dataset and extract meaningful insights from order, customer, product, payment, and sales information.

The analysis demonstrates fundamental SQL skills including data extraction, filtering, sorting, grouping, and aggregation. The objective is to use SQL queries to identify patterns and trends that can support business decision-making.

## Projective Objectives
The main objectives of this project are to:

1. Use SELECT queries to extract relevant information from the dataset.
2. Use WHERE to filter records based on specific conditions.
3. Use ORDER BY to sort and rank results.
4. Use GROUP BY to analyze data across different categories.
5. Apply basic aggregate functions including COUNT(), SUM(), and AVG().
6. Identify meaningful business insights from the query results.
7. Demonstrate practical application of SQL fundamentals to a real-world dataset.

## SQL Skills Demonstrated

This project demonstrates the use of:

SELECT

WHERE

ORDER BY

GROUP BY

COUNT()

SUM()

AVG()

The project also demonstrates combining multiple SQL concepts within a single query to answer practical business questions.
